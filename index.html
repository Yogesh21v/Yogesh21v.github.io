// a bit about me

I'm a software engineer who likes building things end-to-end — schema to API to UI to production. Right now I'm a Junior Software Engineer at NowforceAI, where I own a full-stack billing and finance module (Node.js/Express, MySQL) inside a production applicant-tracking system: database design, REST APIs, frontend, and deployment, all mine to ship and keep alive.

Before that, I was an R&D Intern at Imagine Marketing (boAt), building a Python framework and Flask dashboard to predict battery health in wireless earbuds from real telemetry — my first real taste of turning messy sensor data into something a product team could actually use.

I'm finishing my M.S. in Computer & Information Science at the University of Michigan–Dearborn (3.94 GPA), and I spend a lot of my own time building AWS-serverless side projects — a face-recognition access system, a Rekognition-based photo analysis pipeline, a Bayesian search engine, even a lip-reading model — mostly because "how would I actually build this" is more fun to answer than to wonder about. My core strength is object-oriented design (Java, Spring Boot, Hibernate) paired with hands-on cloud and full-stack experience, and I'm looking to bring both to a Java backend role.
